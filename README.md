# Portfolio Website

This is a personal Portfolio website project built with React and Vite, designed to professionally showcase personal information, projects, skills, and resume.

## Features

- **Home**: Self-introduction with engaging animations
- **About**: Detailed personal background, skills, and experience
- **Projects**: Showcasing completed projects
- **Resume**: Display and download CV

## Technologies Used

- React 17
- React Router v6
- React Bootstrap
- React PDF
- React Typewriter Effect
- React Particles
- Vite

## Installation

1. Clone the project:

```bash
git clone https://github.com/Hai1205/Portfolio.git
cd portfolio
```

2. Install the packages:

```bash
npm install
```

3. Run the application in development mode:

```bash
npm run dev
```

4. Build the application for production:

```bash
npm run build
```

## Customization

- Replace personal information in components
- Update the PDF resume file in the `src/Assets` directory
- Add project images in `src/Assets/Projects`

## Deployment

This project can be deployed to various platforms such as Vercel, Netlify, GitHub Pages, etc.

```bash
# Run project
npm run dev
```
